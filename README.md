# MILLENIUM HUD 2.0 — «glass edition»

**Hello from Spotik.** Полностью переработанный HUD для **Assetto Corsa (CSP)**:
плавающие «острова» из матового стекла в стилистике Hyprland, радар машин,
телеметрия. Один файл Lua, без зависимостей и внешних ассетов.

> Дизайн можно посмотреть **не заходя в игру**: `preview.html` — интерактивный
> макет с той же геометрией, живой телеметрией, ползунками и перетаскиванием.

---

## Что нового относительно 1.4.3

| Было (1.4.x) | Стало (2.0) |
|---|---|
| Одна панель-полоса внизу, панель «уезжала» при перетаскивании | Каждый остров двигается отдельно, **перетаскивание не может уехать** (см. ниже) |
| Стекло — плоский тёмный прямоугольник | Матовое стекло: градиент, светлая кромка, блик, мягкая тень, акцентный ореол, скругления |
| Радар удалён из HUD | **Радар машин** (идея `carRadar`) переписан на Lua: диск, кольца, блипы с курсом, предупреждения «слева/справа/сзади» |
| 4 виджета | 10 виджетов: спидометр (3 стиля), передача, педали, шины, радар, сессия, топливо, повреждения, индикаторы, подпись |
| Жёсткая вёрстка в пикселях | Дизайн-пиксели: масштаб 60–160 %, корректно при любом разрешении |
| Панель всегда перехватывала клики | Интерактивность **только в режиме редактирования** |
| Падение HUD при отсутствующем поле CSP | Слой безопасного чтения телеметрии + вкладка «Диагностика» |

## Починка перетаскивания (главное)

В 1.4.x окно HUD двигалось вслед за мышью, а позиция считалась как
`позиция окна + позиция мыши`. Окно само является частью этой формулы,
поэтому каждый кадр к сдвигу добавлялся один и тот же дельта-член —
панель начинала ускоряться и улетала «хрен пойми куда». Плюс кнопка мыши
по-разному виделась в момент старта drag.

В 2.0:

* HUD — **одно полноэкранное прозрачное окно в точке (0, 0)**. Координаты
  мыши и координаты экрана — это одно и то же число, а само окно во время
  перетаскивания не двигается. Обратной связи физически нет.
* Позиция острова считается **абсолютно**: `центр = мышь − захват`.
  Никакого накопления дельт.
* Позиции хранятся **в долях экрана (0…1)**, поэтому раскладка не ломается
  при смене разрешения и масштаба интерфейса.
* Магнит к центральной оси и к линии 87 % высоты + направляющие.
* Тянуть нечего случайно: перетаскивание включается тумблером
  **«Режим редактирования»**, а вне его окно вообще не перехватывает мышь.
  Автовыход из режима — 25 секунд бездействия.

Это проверено автотестом: 20 шагов мыши по 10 px дают ровно 200 px сдвига,
без ускорения и без дрейфа при неподвижной мыши (см. `tests/`).

## Виджеты

| Виджет | Что показывает |
|---|---|
| **Спидометр** | Скорость + передача + тахометр. Три стиля: **полоса RPM** (сегментная, как в F1), **круговой прибор** с дугой, засечками и стрелкой, **минимал** (только цифры и тонкая полоса). Лимитер читается из `engine.ini` — красная зона всегда по делу. Вспышка у отсечки с настраиваемым порогом. |
| **Передача** | Плашка с крупной цифрой (`R / N / 1…n`). Встроена в спидометр или может жить отдельным островом. |
| **Педали** | GAS / BRK / CLT / HB с процентами; `CLT` показывает **нажатие** (idle = 0 %, кик сцепления — всплеск). Семантические цвета или монохромный акцент. |
| **Шины** | 2×2: температура ядра цветом (серая <75°, зелёная 75–100°, жёлтая 100–115°, красная 115°+), износ в % и полосой. |
| **Радар** | См. ниже. |
| **Сессия** | Позиция `P4/12`, круг `4/10`, `CUR` (живой круг), `LAST`, `BEST`. LAST подсвечивается зелёным при новом лучшем. Круги считаются **сами** (по сбросу `lapTimeMs`), поэтому виджет не зависит от необязательных полей CSP. |
| **Топливо** | Литры, полоса, расход на круг и **оценка остатка кругов** (расход считается по факту между кругами). |
| **Повреждения** | FL / FR / RL / RR полосами и процентами — если сборка CSP отдаёт `car.damage`. |
| **Индикаторы** | ABS / TC / HB / свет / пита-лимитер — показываются только те, что реально есть в сборке. |
| **Подпись** | `MILLENIUM · HUD · v2.0 · SPOTIK`. |

## Радар машин

Идея и логика — из **carRadar** (Itsjustdel), но всё переписано на Lua внутри
HUD: отдельный Python-апп больше не нужен, блипы рисуются векторно, дизайн —
тот же стеклянный.

* **Диск** с кольцами дистанции (3 кольца), осями и маркером своей машины.
* **Блипы** — короткий штрих **вдоль курса** каждой машины: видно, кто едет
  прямо, кто поворачивает, кто стоит боком.
* **Цвет по дистанции**: акцент → жёлтый (< 9 м) → красный (< 3.5 м), плюс
  ореол у близких машин.
* **Предупреждения**: дуга у края диска и шеврон слева/справа, когда машина
  в слепой зоне (`|бок|>1.4 м` и `сзади <3 м`), плюс отдельный случай
  «прямо сзади».
* **Режимы**: «по машине» (диск вращается с вами) и «по северу».
* **Дальность** 8–60 м, размер блипов, подписи дистанции, авто-затухание,
  когда рядом никого.
* Подвал: ближайшая машина и направление — `6.1 М · СЗАДИ-СЛЕВА`.

Отличия от оригинального carRadar осознанные: нет 3D-мешей машин из KN5
(в оригинале для этого распаковывается модель через `kn5conv.exe`) — вместо
этого быстрый штрих с курсом, который читается не хуже и стоит десятки
наносекунд; нет флагов/синих флагов — они требуют MP-логики.

## Настройки

Окно приложения (иконка на панели AC). Пять вкладок:

1. **Виджеты** — профили раскладки (`Гонка`, `Минимал`, `Трек-день`, `Сброс`),
   включение каждого виджета, стиль спидометра, порог вспышки, число сегментов.
2. **Радар** — дальность, режим вращения, предупреждения, подписи, размер блипов.
3. **Вид** — плотность стекла, масштаб, скругление, тень, блик, свечение,
   палитра акцентов (6 пресетов) + свой цвет пипеткой.
4. **Раскладка** — режим редактирования, сброс позиций, текущие координаты
   и размеры каждого острова.
5. **Диагностика** — что доступно в вашей сборке CSP: DWrite, разрешение,
   дизайн-пиксель, лимитер, число машин, и список полей телеметрии
   с отметками «есть / нет».

## Устойчивость

* Все необязательные поля читаются через слой проб: имя поля проверяется
  **один раз** (`pcall`), результат кешируется. Дальше — обычное чтение.
  Нет поля — виджет рисует `—`, а не падает.
* Нет машины (загрузка, реплей, выход из сессии) — HUD тихо ничего не рисует.
* `dt` может прийти `nil` — подставляется 1/60, анимации не замирают.
* Нет DWrite (старый CSP) — автоматический откат на встроенные кегли.
* Нет `tabBar` — настройки рисуются одной колонкой.
* Дубли `vec2`/`rgbm` не создаются каждый кадр: пулы объектов (меньше
  нагрузки на GC при сотнях примитивов в кадре).

## Установка

1. Скопируйте папку `MilleniumHUD` в `assettocorsa\apps\lua\` (или
   перетащите zip в Content Manager).
2. Включите приложение **Millenium HUD** в списке приложений.
3. Настройки — по иконке в боковой панели.
4. Поставьте галочку **Режим редактирования**, разложите острова мышью,
   снимите галочку.

Требуется CSP с Lua-приложениями (0.1.76+). Для крупных цифр произвольного
кегля — сборка с DWrite-текстом (0.1.79+); без него HUD тоже работает.
