### 📡 Радар

Идея и логика — из **carRadar**, но переписано на Lua внутри HUD: без
Python-аппа, без распаковки 3D-моделей машин.

- диск с тремя кольцами дистанции и маркером своей машины;
- блипы — **короткий штрих вдоль курса** каждой машины (видно, кто поворачивает);
- цвет по дистанции: акцент → жёлтый (< 9 м) → красный (< 3.5 м);
- **предупреждения** слева/справа/сзади: дуга у края диска + шеврон;
- режимы «по машине» / «по северу», дальность 8–60 м;
- подвал: `6.1 М · СЗАДИ-СЛЕВА`.

### 🖱 Починенное перетаскивание

В 1.4.x панель «уезжала хрен пойми куда». Причина — окно HUD двигалось само,
а позиция считалась как `позиция окна + позиция мыши`: окно входило в формулу
само для себя, и каждый кадр добавлялся один и тот же дельта-член — панель
разгонялась.

В 2.0 HUD живёт в **одном полноэкранном прозрачном окне в `(0, 0)`**:

- координаты мыши и экрана — одно и то же число;
- окно во время перетаскивания не двигается;
- позиция считается абсолютно: `центр = мышь − захват`, без накопления;
- позиции хранятся **в долях экрана** — раскладка не ломается при смене разрешения;
- магнит к центру + направляющие, автовыход из режима через 25 с.

### 🛡 Устойчивость

<details>
<summary><b>Что сделано, чтобы HUD не падал и не мешал (развернуть)</b></summary>

<br>

- **Слой безопасного чтения телеметрии**: необязательные поля CSP проверяются
  один раз (`pcall`), результат кешируется. Нет поля — виджет показывает `—`,
  а не роняет HUD в лог.
- **Вкладка «Диагностика»** в настройках: видно, какие поля отдаёт ваша сборка.
- Нет машины (загрузка, реплей) — HUD тихо ничего не рисует.
- `dt == nil` — подставляется 1/60, анимации не замирают.
- Нет DWrite-текста (старый CSP) — автоматический откат на встроенные кегли.
- Нет `tabBar` — настройки рисуются одной колонкой.
- Вне режима редактирования окно **не перехватывает клики** — HUD не мешает
  нажимать кнопки в игре.
- Пулы `vec2`/`rgbm` и сглаживание, не зависящее от FPS.

</details>

## 🚀 Установка

**Content Manager:** перетащите [`MilleniumHUD-2.0.zip`](MilleniumHUD-2.0.zip) в окно CM.

**Вручную:** распакуйте в `assettocorsa\apps\lua\` так, чтобы получилось
`assettocorsa\apps\lua\MilleniumHUD\manifest.ini`.

Затем:

1. Включите приложение **Millenium HUD** в списке приложений.
2. Откройте настройки (иконка на панели) → **Раскладка** → *Режим редактирования*.
3. Разложите острова мышью, снимите галочку.

> Требуется CSP с Lua-приложениями (0.1.76+). Крупные цифры произвольного
> кегля — на сборках с DWrite-текстом (0.1.79+); без него HUD тоже работает.
